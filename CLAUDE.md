# ContextIQ Project Instructions

Build this as a production-grade AI engineering portfolio project.

- Use Anthropic SDK only for LLM calls.
- Keep all prompts in `prompts/`.
- Preserve citations through every ingestion, retrieval, and context assembly step.
- Every context packet must report token budget, selected sources, dropped candidates, and citation metadata.
- MCP tools must be read-only unless explicitly approved.
- Prefer simple working CLI behavior before frontend polish.
